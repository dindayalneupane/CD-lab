The purpose of this lab is to design and implement a fundamental Lexical Analyzer (Scanner) using Flex to recognize and classify standard programming tokens such as keywords, identifiers, numbers, operators, and separators. Lexical analysis serves as the frontline phase of a compiler, parsing a continuous stream of input source characters and grouping them into valid vocabulary units called lexemes based on predefined rules. This specific program leverages the power of Flex to translate modular regular expression definitions—like DIGIT, ID, KEYWORD, OP, and SEPARATOR—into a fast Deterministic Finite Automaton (DFA) state machine. The script utilizes the %option noyywrap directive to automatically terminate execution at the End-Of-File (EOF) without requiring an explicit helper function, while tracking structural layout through a dedicated newline rule (\n) that maintains a running line_no count. During the execution cycle, the main() function calls the core scanning engine yylex(), which captures each lexeme inside the global variable yytext and instantly prints its designated classification to the console. The rule hierarchy ensures that strict programming constraints are maintained—such as prioritizing the KEYWORD pattern over general ID strings to prevent reserved terms from being misidentified as user-defined variables—while any anomalous characters are safely caught by a fallback dot (.) pattern.
